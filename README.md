# Modelling Synaptic Plasticity

An interactive Python/Jupyter teaching resource introducing computational models of **synaptic plasticity** for my current students learning about neurophysiology.

The notebook covers two core forms of synaptic plasticity:

- **Short-term synaptic plasticity (STP)** — modelling presynaptic short-term depression and exploring how release probability, recovery time constants, and presynaptic firing rate shape postsynaptic responses.
- **Spike-timing-dependent plasticity (STDP)** — modelling how the relative timing of pre- and postsynaptic spikes produces long-term potentiation (LTP) or long-term depression (LTD).

Exercises include manipulating model parameters, fitting a short-term depression model to experimental-like data, exploring the STDP learning rule, and calculating synaptic weight changes from spike trains.

## Requirements

The notebook uses Python with:

- NumPy
- Matplotlib
- Seaborn

## Getting started

Open `Synaptic_plasticity_notebook.ipynb` in Jupyter Notebook or JupyterLab and work through the sections sequentially/seriatim. The notebook combines background material, mathematical models, executable code, visualisations, and exercises.

## Intended use

This resource is designed for teaching introductory **computational neuroscience and synaptic physiology**, and assumes basic familiarity with neuronal signalling and Python.
